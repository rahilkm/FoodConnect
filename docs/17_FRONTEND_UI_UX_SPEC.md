# 17 Frontend UI UX Spec

## Design principles
- trustworthy
- operationally clear
- role-oriented
- data-rich without feeling cluttered
- strong status visibility
- mobile usable, desktop strong

## Main shells
1. public marketing shell
2. authenticated donor shell
3. authenticated NGO shell
4. authenticated volunteer shell
5. admin shell

## Public pages
- home
- about
- how it works
- NGO discovery
- contact
- login
- register

## Donor pages
- dashboard
- create donation
- donation details
- tracking timeline
- recurring support
- impact reports
- profile

## NGO pages
- dashboard
- incoming donations
- donation detail

- hotspot detail
- routes
- route detail
- volunteers
- analytics

## Volunteer pages
- dashboard
- my routes

## Admin pages
- dashboard

## UI components
- stat card
- badge
- map panel
- NGO recommendation card
- donation step timeline
- hotspot card
- route progress card
- proof gallery
- audit table
- analytics chart cards
- empty states
- dialogs and drawers

## Form UX
- inline validation
- sensible defaults
- disabled submit until valid
- success/error toast
- preserved drafts where appropriate

## Visual semantics
- trusted/verified = green
- warning/urgency = amber
- displaced/blocked = red
- in progress = blue
- pending review = purple or slate
