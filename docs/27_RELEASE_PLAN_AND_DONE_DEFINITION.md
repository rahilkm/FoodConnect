# 27 Release Plan And Done Definition

- users

- basic frontend shells

## Phase 2

- recommendation UI

## Phase 3
- hotspots
- routes

- volunteer dashboard

## Phase 4
- recurring support
- notifications
- analytics
- admin moderation

## Phase 5
- tests
- polish
- seed data validation
- docs cleanup

## Done definition
The project is done when:
- all roles can authenticate
- Mongo persists all core entities
- donor to NGO flow completes
- NGO to needy route flow completes
- displaced hotspot reroute completes
- recurring support generates donation instances
- admin can verify NGO and see audit log
- app starts locally from clean setup
- core tests pass
