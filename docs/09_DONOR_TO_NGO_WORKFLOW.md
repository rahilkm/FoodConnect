# 09 Donor To NGO Workflow

## Goal
Help donors donate with confidence by reducing guesswork and providing visibility.

## Flow
1. Donor registers/logs in
2. Donor fills donation form
3. Backend validates donation content
4. Matching engine scores NGOs
5. Frontend shows top recommendations with reasons
6. Donor selects NGO or confirms best match
7. Donation is posted
8. NGO accepts or declines
9. Volunteer gets assigned if pickup required
10. Pickup is completed
11. Delivery is completed
12. Impact summary is recorded
13. Donor sees full timeline and proof

## Donation form fields
- donation type
- food category
- preparation time
- expiry time
- quantity and units
- temperature/storage notes
- pickup required
- pickup address
- geo coordinates
- allergen notes optional
- image attachments optional
- instructions

## Recommendation card content
- NGO name
- verification badge
- service area
- accepted types
- current need level
- estimated pickup ETA
- average response time
- reliability score
- reasons for recommendation
- distance
- capacity status

## Donor views
- active donations
- completed donations
- recurring support plans
- impact reports
- receipts or acknowledgement if enabled
